Monitoramento

O que é o número em cada cartão? É o RMSE relativo R: o erro do modelo campeão dividido pelo erro da média sazonal (o benchmark do artigo), nos 12 meses mais recentes com valor realizado.

  • R < 1: o modelo erra menos que a média sazonal. Ex.: 0,90 = erra 10% menos.
  • R = 1: empate. O modelo não agrega nada ao benchmark.
  • R > 1: o modelo erra mais que a média sazonal. Ex.: 1,20 = erra 20% mais.
